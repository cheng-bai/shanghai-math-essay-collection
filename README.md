# 上海数学大题分类汇编

静态阅读版：253道大题，包含考点、答案、解析、学校与原题号。通过网页可分类、搜索并下载Markdown分册。

答案解析沿用源稿，未逐题独立重算；收录范围与限制见[收录说明](收录说明.md)。

## 首版

- 版本：v1.0.0。
- 网站：https://cheng-bai.github.io/shanghai-math-essay-collection/
- 静态文件通过GitHub Actions发布到GitHub Pages，无后端数据库。
- 公开发布不代表对题目与题图拥有排他版权；原试题和题图的权利归其相应权利人。未对整包原始材料授予新的开源许可。
- 单独下载的Markdown引用本包assets题图；离线保留图片请下载整个仓库，并保持目录结构。
- 更新main分支不会自动部署；检查题目数量、公式、图片和公开范围后，手动运行Publish static site工作流发布。
