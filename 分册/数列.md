### 188 · 原第19题

**来源：** S045 · 上海市七宝中学 · 高三 · 2025-2026 · 期中 · 原第19题

**考点说明：** 对递推式取倒数构造等差数列，求通项并裂项求和证明不等式。

已知数列 $\left\{ a _ { n } \right\}$ 满足 $. a _ { 1 } = 1 , a _ { n + 1 } = \frac { a _ { n } } { 3 a _ { n } + 1 } ( n \in \mathrm { N } ^ { * } )$

<sup>(1)</sup> 求证： $\left\{ { \frac { 1 } { a _ { n } } } \right\}$ 是等差数列，并求 $\left\{ a _ { n } \right\}$ 的通项公式；

(2) 记 $S _ { n } = a _ { 1 } a _ { 2 } + a _ { 2 } a _ { 3 } + \cdots + a _ { n } a _ { n + 1 }$ ，证明 $S _ { n } < { \frac { 1 } { 3 } }$

#### 答案

(1) 证明见解析， $a _ { n } = { \frac { 1 } { 3 n - 2 } }$

(2) 证明见解析.

#### 解析（保留源稿）

(1) $\operatorname { H } a _ { n + 1 } = { \frac { a _ { n } } { 3 a _ { n } + 1 } }$ ，两边取倒数，可得 ${ \frac { 1 } { a _ { n + 1 } } } = { \frac { 1 } { a _ { n } } } + 3 .$

即有数列 $\left\{ { \frac { 1 } { a _ { n } } } \right\}$ 是首项 ${ \frac { 1 } { a _ { 1 } } } = 1$ ，公差 $d = 3$ 的等差数列，

由等差数列的通项公式，可得 ${ \frac { 1 } { a _ { n } } } = 1 + ( n - 1 ) \times 3 = 3 n - 2$ ，故 $\tan = { \frac { 1 } { 3 n - 2 } }$

(2) $\forall a _ { n } a _ { n + 1 } = { \frac { 1 } { ( 3 n - 2 ) \left( 3 n + 1 \right) } } = { \frac { 1 } { 3 } } \left( { \frac { 1 } { 3 n - 2 } } - { \frac { 1 } { 3 n + 1 } } \right)$

可得

$$
\begin{array}{l} S _ {n} = a _ {1} a _ {2} + a _ {2} a _ {3} + \ldots + a _ {n} a _ {n + 1} = \frac {1}{3} \\ \left[ \left(1 - \frac {1}{4}\right) + \left(\frac {1}{4} - \frac {1}{7}\right) + \ldots + \left(\frac {1}{3 n - 2} - \frac {1}{3 n + 1}\right) \right] \\ = \frac {1}{3} \left(1 - \frac {1}{3 n + 1}\right) <   \frac {1}{3}. \end{array}
$$

### 189 · 原第17题

**来源：** S041 · 上海市六校期中联考 · 高三 · 2025-2026 · 期中 · 原第17题

(1) 求 $\left\{ a _ { n } \right\}$ 的通项公式；

(2) 设 $\cdot b _ { n } = a _ { n } + 2 n$ ，求数列 $\left\{ b _ { n } \right\}$ 的前n项和 $S _ { n }$

#### 答案

(2) $S _ { n } = 2 ^ { n } - 1 + n ^ { 2 } + n$

#### 解析（保留源稿）

(1) 因为等比数列 $\{ a _ { n } \}$ 满足 $a _ { 1 } + a _ { 2 } = 3 , a _ { 4 } + a _ { 5 } = 2 4$

所以

$$
\begin{array}{l} S _ {n} = b _ {1} + b _ {2} + b _ {3} + \dots + b _ {n} = 2 ^ {0} + 2 \times 1 + 2 ^ {1} + 2 \times 2 + 2 ^ {2} + 2 \times 3 + \dots + 2 ^ {n - 1} + 2 n = \\ \frac {1 \times (1 - 2 ^ {n})}{1 - 2} + 2 \times \frac {n (n + 1)}{2} = 2 ^ {n} - 1 + n ^ {2} + n \end{array}
$$

### 191 · 原第21题

**来源：** S003 · 华东师范大学第二附属中学 · 高三 · 2025-2026 · 期中 · 原第21题

**考点说明：** 幂数集分拆与等比求和，利用奇偶性和整数根条件研究元素和。

> **校订提示**
>
> 源稿在第 20 题解析之后**缺“21”题号**，直接给出本题题干（全文末题）；依题号严格递增补为第 21 题。另答案行“2 <sup>n</sup>2 $+2^{\frac{n}{2}+1}-2$”为残形，据解析应为 $2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2$。

> 下列正文保留原转录；与本提示冲突的文字或公式不作为有效依据。

已知数集 $\Omega=\left\{2^{0},2^{1},\cdots,2^{n}\right\}\ (n\in\mathbf{N}^{*})$。若 $\Omega$ 的两个非空子集 $T_{1}$ 和 $T_{2}$ 满足：$T_{1}\cap T_{2}=\varnothing$，$T_{1}\cup T_{2}=\Omega$，则称集合 $T_{1}$ 和 $T_{2}$ 是 $\Omega$ 的一个“分拆”。已知 $A$ 和 $B$ 是 $\Omega$ 的一个分拆，$S(M)$ 表示数集 $M$ 中所有元素的和。

(1) 若 $n=10$，$A=\{x\mid x=2^{2k-1},\ k=1,2,3,4,5\}$，求 $S(B)$；（用数值表示）

(2) 证明：$S(A)\ne S(B)$；

(3) 若 $n$ 为给定的偶数，关于 $x$ 的方程 $x^{2}-S(A)x+S(B)=0$ 有整数根，求 $S(A)$ 的最小值，并写出取到最小值时的所有的集合 $A$。

#### 答案

(1) $1365$　(2) 证明见解析　(3) $2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2$；$A=\left\{2,4,8,\cdots,2^{\frac{n}{2}-2},2^{\frac{n}{2}-1},2^{\frac{n}{2}+1}\right\}$

#### 解析（保留源稿）

(1) 由题，当 $n=10$ 时，

$$
S(\Omega)=1+2+2^{2}+\cdots+2^{10}=\dfrac{1\times(2^{11}-1)}{2-1}=2047.
$$

又 $S(A)=2+2^{3}+2^{5}+2^{7}+2^{9}=2\times\dfrac{4^{5}-1}{4-1}=682$，结合题意 $S(A)+S(B)=S(\Omega)$，

则 $S(B)=S(\Omega)-S(A)=2047-682=1365$。

(2) 证明：由题可知 $S(A)$、$S(B)$ 均为正整数。假设 $S(A)=S(B)$，由 $S(A)+S(B)=S(\Omega)$ 得

$$
S(A)=S(B)=\dfrac{S(\Omega)}{2}.
$$

注意到 $S(\Omega)=1+2+2^{2}+\cdots+2^{n}=2^{n+1}-1$ 为奇数，则 $\dfrac{S(\Omega)}{2}$ 不为整数，这与 $S(A)$、$S(B)$ 均为正整数相矛盾，故 $S(A)\ne S(B)$。

(3) 设 $S(A)=t$，由（2）可知 $S(\Omega)=2^{n+1}-1$，又 $S(A)+S(B)=S(\Omega)$，则

$$
x^{2}-S(A)x+S(B)=0\ \Longleftrightarrow\ x^{2}-tx+(2^{n+1}-1-t)=0.
$$

因其有整数根，则其判别式 $\Delta=t^{2}-4(2^{n+1}-1-t)=(t+2)^{2}-2^{n+3}$ 为完全平方数（否则根一定含 $\sqrt{\Delta}$ 为无理数，与题意不符）。

设 $\Delta=(t+2)^{2}-2^{n+3}=m^{2}$，其中 $m\in\mathbf{N}^{*}$。则

$$
(t+2)^{2}-m^{2}=2^{n+3}\ \Rightarrow\ (t+2-m)(t+2+m)=2^{n+3}.
$$

因 $n,t,m$ 均为正整数，则 $\begin{cases}t+2-m=2^{\lambda}\\ t+2+m=2^{\mu}\end{cases}$，其中 $\lambda+\mu=n+3$，$\lambda,\mu\in\mathbf{N}^{*}$，则 $t=\dfrac{2^{\lambda}+2^{\mu}}{2}-2$。

构造函数 $f(x)=2^{x}+2^{n+3-x}$，其中 $x>0$，则 $f'(x)=2^{x}\ln 2-2^{n+3-x}\ln 2$。令 $g(x)=f'(x)$，则 $g'(x)=(\ln 2)^{2}\left(2^{x}+2^{n+3-x}\right)>0$，故 $g(x)=f'(x)$ 在 $(0,+\infty)$ 上单调递增。

注意到 $f'\left(\dfrac{n+3}{2}\right)=0$，则 $f'(x)>0\Rightarrow x>\dfrac{n+3}{2}$，$f'(x)<0\Rightarrow 0<x<\dfrac{n+3}{2}$，得 $f(x)$ 在 $\left(0,\dfrac{n+3}{2}\right)$ 上单调递减，在 $\left(\dfrac{n+3}{2},+\infty\right)$ 上单调递增。

则 $f(x)=2^{x}+2^{n+3-x}$（$x\in\mathbf{N}^{*}$）要取最小值，$x$ 应为离 $\dfrac{n+3}{2}$ 最近的整数，即 $x=\dfrac{n+2}{2}$ 或 $x=\dfrac{n+4}{2}$。

则 $t=\dfrac{2^{\lambda}+2^{\mu}}{2}-2\ge\dfrac{f}{2}-2$，其中

$$
f=\min\left\{f\left(\dfrac{n+2}{2}\right),\ f\left(\dfrac{n+4}{2}\right)\right\}=2^{\frac{n+2}{2}}+2^{\frac{n+4}{2}}.
$$

即 $S(A)\ge 2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2$，故 $S(A)$ 的最小值为 $2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2$。

注意到

$$
2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2=2^{\frac{n}{2}}-1+2^{\frac{n}{2}+1}-1=1+2+\cdots+2^{\frac{n}{2}-1}+1+2+\cdots+2^{\frac{n}{2}}
=2+4+\cdots+2^{\frac{n}{2}-1}+2^{\frac{n}{2}+1},
$$

因任意正整数在二进制下的表示唯一，则当 $S(A)$ 取最小值 $2^{\frac{n}{2}}+2^{\frac{n}{2}+1}-2$ 时，集合 $A$ 只能为

$$
\left\{2,4,8,\cdots,2^{\frac{n}{2}-2},2^{\frac{n}{2}-1},2^{\frac{n}{2}+1}\right\}.
$$

### 192 · 原第18题

**来源：** S039 · 华东师范大学附属东昌中学 · 高三 · 2025-2026 · 期中 · 原第18题

**考点说明：** 联立等差与等比数列基本量，将通项关系转化为整数指数计数。

已知数列 $\{a_{n}\}$ 为等差数列，$\{b_{n}\}$ 是公比为 2 的等比数列，且 $a_{2}-b_{2}=a_{3}-b_{3}=b_{4}-a_{4}$。

(1) 证明：$a_{1}=b_{1}$；

(2) 若集合 $M=\{k\mid b_{k}=a_{m}+a_{1},\ 1\le m\le 50\}$，求集合 $M$ 中的元素个数。

#### 答案

(1) 证明见解析　(2) $6$

#### 解析（保留源稿）

(1) 证明：设数列 $\{a_{n}\}$ 的公差为 $d$，则

$$
\begin{cases}a_{1}+d-2b_{1}=a_{1}+2d-4b_{1}\\[4pt]a_{1}+d-2b_{1}=8b_{1}-(a_{1}+3d)\end{cases}\ \Longrightarrow\ \begin{cases}d=2b_{1}\\[4pt]a_{1}+2d-5b_{1}=0\end{cases}
$$

解得 $b_{1}=a_{1}=\dfrac{d}{2}$，所以原命题得证。

(2) 由（1）知 $b_{1}=a_{1}=\dfrac{d}{2}$，所以

$$
b_{k}=a_{m}+a_{1}\ \Longleftrightarrow\ a_{1}\cdot 2^{k-1}=a_{1}+(m-1)d+a_{1}.
$$

因为 $a_{1}\ne 0$ 且 $d=2a_{1}$，所以 $a_{m}+a_{1}=a_{1}(2m-1)+a_{1}=2ma_{1}$，于是

$$
a_{1}\cdot 2^{k-1}=2ma_{1}\ \Longrightarrow\ m=2^{k-2}\in[1,50].
$$

由 $2^{k-2}\ge 1$ 得 $k\ge 2$；由 $2^{k-2}\le 50$ 得 $k\le 2+\log_{2}50=3+\log_{2}25$。

又 $2^{4}=16<25<32=2^{5}$，故 $4<\log_{2}25<5$，即 $7<3+\log_{2}25<8$，所以 $k\le 7$。

满足等式的解为 $k=2,3,4,5,6,7$，故集合 $M$ 中的元素个数为 $6$。

### 193 · 原第18题

**来源：** S042 · 上海市浦东新区期中联考 · 高三 · 2025-2026 · 期中 · 原第18题

**考点说明：** 由对数递推式确定等比数列，将严格递增条件转化为参数范围。

已知数列 $\{a_{n}\}$ 满足 $\log_{2}a_{n+1}=1+\log_{2}a_{n}$，且 $a_{1}=2$．

(1) 求 $a_{10}$ 的值；

(2) 若数列 $\left\{a_{n}+\dfrac{\lambda}{a_{n}}\right\}$ 为严格增数列，其中 $\lambda$ 是常数，求 $\lambda$ 的取值范围．

#### 答案

(1) $a_{10}=1024$

(2) $\lambda<8$

#### 解析（保留源稿）

(1) 由 $\log_{2}a_{n+1}=1+\log_{2}a_{n}$ 得 $\log_{2}a_{n+1}=\log_{2}(2a_{n})$，故 $a_{n+1}=2a_{n}$，即 $\dfrac{a_{n+1}}{a_{n}}=2$．

又 $a_{1}=2\ne 0$，故数列 $\{a_{n}\}$ 是以 $2$ 为首项、$2$ 为公比的等比数列，从而 $a_{n}=a_{1}q^{n-1}=2^{n}$．

所以 $a_{10}=2^{10}=1024$．

(2) 设 $b_{n}=a_{n}+\dfrac{\lambda}{a_{n}}=2^{n}+\dfrac{\lambda}{2^{n}}$．

因为数列 $\{b_{n}\}$ 为严格增数列，故

$$
b_{n+1}-b_{n}=\left(2^{n+1}+\frac{\lambda}{2^{n+1}}\right)-\left(2^{n}+\frac{\lambda}{2^{n}}\right)=2^{n}-\frac{\lambda}{2^{n+1}}>0
$$

对正整数 $n$ 恒成立，即 $\lambda<2^{2n+1}$ 对正整数 $n$ 恒成立．

当 $n=1$ 时，$2^{2n+1}$ 取到最小值 $8$，所以 $\lambda<8$．

#### 解析（保留源稿）

(1) 因为 $a_{n+1}=3a_{n}-4$ ，即 $a_{n+1}-2=3(a_{n}-2)$ ,

又 $b_{n}=a_{n}-2$ ，即 $b_{n+1}=3b_{n}$ ，又 $a_{1}=3$ ，所以 $b_{1}=a_{1}-2=1$ ，

所以 $\{b_{n}\}$ 是以1为首项，3为公比的等比数列；

(2) 由（1）可得 $b_{n}=a_{n}-2=1\times3^{n-1}$ ,

所以 $a_{n}=3^{n-1}+2,$

$$
\begin{array}{l} {\text {所以} S _ {n} = 3 ^ {0} + 2 + 3 ^ {1} + 2 + \dots + 3 ^ {n - 1} + 2} \\ {= \left(3 ^ {0} + 3 ^ {1} + \dots + 3 ^ {n - 1}\right) + 2 n} \\ {= \frac {3 ^ {0} \times (1 - 3 ^ {n})}{1 - 3} + 2 n = \frac {3 ^ {n} - 1}{2} + 2 n.} \end{array}
$$
